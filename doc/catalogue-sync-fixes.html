01

两个问题，需要分别处理

P1 让无效扫描输入返回错误，P2 把错误以正确的进程状态传给调用方。两项修复共同完成从输入检查到失败报告的链路。

P1 / 数据正确性

非目录被当成空树

普通文件也会进入 WalkDir 的根回调。当前代码直接跳过根节点，可能成功返回空列表，使比较逻辑把原树后代及文章全部判为删除。

P2 / 失败可见性

失败仍以状态 0 结束

book.Build() 失败后，main 使用标准输出打印错误并正常返回。脚本或定时任务收到的退出码仍为成功。

  • scan/scan.go先拒绝空字符串，再统一根路径表示方式。
  • scan/walker.go在根回调中检查 d.IsDir()，类型不符立即返回错误。
  • main.go同步错误写入 os.Stderr，随后调用 os.Exit(1)。

这是修复提案。下方代码已应用到临时项目副本进行验证；本次任务没有修改你的现有 Go 文件。

步骤 A：更新 scan/scan.go

下面是完整文件参考。先检查空字符串，再调用 filepath.Clean()。Clean("") 会得到 "."，顺序相反会把缺失参数意外变成当前目录。

scan/scan.go · 完整文件
29 行 · Go
package scan

import (
	"fmt"
	"path/filepath"
)

// Dir 本函数用于递归遍历给定的目录,返回所有普通文件的路径列表.该路径列表为相对给定目录 dir 的路径,分隔符统一为 /
// Tips:
// 1. 在递归过程中,会跳过隐藏项
// 2. 在递归过程中,会跳过符号链接
func Dir(dir string) ([]string, error) {
	// 必须在 Clean 之前判断；Clean("") 会得到 "."。
	if dir == "" {
		return nil, fmt.Errorf("扫描根路径不能为空")
	}
	dir = filepath.Clean(dir)

	w := &walker{
		root: dir,
	}

	err := filepath.WalkDir(dir, w.visit)
	if err != nil {
		return nil, fmt.Errorf("扫描目录失败: %w", err)
	}

	return w.files, nil
}

步骤 B：更新 scan/walker.go

在导入中增加 fmt，并替换原来“根节点直接返回”的分支。下面给出完整文件参考；访问错误仍在函数最前面处理。

scan/walker.go · 完整文件
62 行 · Go
package scan

import (
	"fmt"
	"io/fs"
	"path/filepath"
	"strings"
)

// walker 本结构体表示一次目录树扫描的遍历状态
type walker struct {
	root  string   // root 被扫描的根目录 用于识别根目录自身和生成相对路径
	files []string // files 扫描出的所有普通文件的相对路径列表
}

// visit 本方法用于处理 filepath.WalkDir 的回调逻辑,并将扫描出的普通文件路径收集到 walker.files 中
func (w *walker) visit(path string, d fs.DirEntry, err error) error {
	// WalkDir 自身读取出错 则直接终止 不产出结果
	if err != nil {
		return err
	}

	// 根路径必须是实际目录。普通文件、根软链接等都返回错误。
	if path == w.root {
		if !d.IsDir() {
			return fmt.Errorf("扫描根路径必须是实际目录: %q", path)
		}
		return nil
	}

	// 跳过隐藏项 (目录整枝跳过 文件单个跳过)
	if strings.HasPrefix(d.Name(), ".") {
		if d.IsDir() {
			return filepath.SkipDir
		}

		return nil
	}

	// 跳过符号链接
	if d.Type()&fs.ModeSymlink != 0 {
		return nil
	}

	// 目录本身不产出
	if d.IsDir() {
		return nil
	}

	// 非普通文件(设备文件/socket)跳过
	if !d.Type().IsRegular() {
		return nil
	}

	rel, err := filepath.Rel(w.root, path)
	if err != nil {
		return err
	}
	w.files = append(w.files, filepath.ToSlash(rel))

	return nil
}

合法空目录仍然允许同步。 空结果本身不代表错误。真实空目录成功返回空列表后，按镜像同步规则删除旧后代是有效操作。应拒绝的是错误的根路径类型。

根软链接的处理

沿用原有跳过软链接的规则，根路径本身是软链接时明确返回错误。先规范化路径，也能统一处理结尾带 / 或 /. 的输入。

已有扫描行为

目录内部的隐藏项、软链接、非普通文件继续按已有规则跳过；隐藏根目录仍可扫描。原有扫描测试已一起运行。

这项修复校验扫描根节点类型，不提供文件系统内容的原子快照，也不等同于禁止所有中间路径组件中的软链接。

完整 main() 参考

替换 main() 函数即可，沿用文件中现有的导入和 run() 初始化实现。所用 fmt、os 已经存在。

func main() {
	err := run()
	if err != nil {
		fmt.Fprintf(os.Stderr, "%v\n", err)
		os.Exit(1)
	}

	path := flag.String("path", "", "待处理的目录路径 (必填)")
	bookID := flag.Int64("bookID", 0, "书籍ID (必填, 正整数)")
	flag.Parse()

	book := &biz.Book{}
	report, err := book.Build(*bookID, *path)
	if err != nil {
		fmt.Fprintf(os.Stderr, "构建书籍目录失败: %v\n", err)
		os.Exit(1)
	}

	fmt.Printf("构建书籍目录成功:\n")
	fmt.Printf("书籍ID: %d\n", book.ID)
	fmt.Printf("新增目录数: %d\n", report.CatalogueReport.AddItemQuantity)
	fmt.Printf("删除目录数: %d\n", report.CatalogueReport.DeleteItemQuantity)
	fmt.Printf("新增文章数: %d\n", report.ArticleReport.AddItemQuantity)
	fmt.Printf("删除文章数: %d\n", report.ArticleReport.DeleteItemQuantity)
}

进程退出放在 main 层。 os.Exit() 会立即终止进程，尚未执行的 defer 不会运行。model / biz 层继续返回错误；事务函数返回时先完成自己的回滚清理，main 再打印错误并退出。

只修复退出码还不能挡住 P1：如果扫描没有返回错误，main 根本不会进入失败分支。因此两项修复都需要接入。

package scan_test

import (
	"os"
	"path/filepath"
	"testing"
	"treeSync/scan"
)

func TestDirRejectInvalidRoots(t *testing.T) {
	t.Run("ordinary_file", func(t *testing.T) {
		file := filepath.Join(t.TempDir(), "chapter.md")
		if err := os.WriteFile(file, []byte("content"), 0600); err != nil {
			t.Fatal(err)
		}
		if _, err := scan.Dir(file); err == nil {
			t.Fatal("普通文件必须返回错误")
		}
	})

	t.Run("empty_path", func(t *testing.T) {
		if _, err := scan.Dir(""); err == nil {
			t.Fatal("空路径必须返回错误")
		}
	})

	t.Run("missing_path", func(t *testing.T) {
		missing := filepath.Join(t.TempDir(), "missing")
		if _, err := scan.Dir(missing); err == nil {
			t.Fatal("不存在的路径必须返回错误")
		}
	})

	t.Run("symlink_root", func(t *testing.T) {
		target := t.TempDir()
		link := filepath.Join(t.TempDir(), "book-link")
		if err := os.Symlink(target, link); err != nil {
			t.Skipf("当前环境不支持创建软链接: %v", err)
		}
		for _, path := range []string{
			link,
			link + string(os.PathSeparator),
			link + string(os.PathSeparator) + ".",
		} {
			if _, err := scan.Dir(path); err == nil {
				t.Errorf("根软链接必须返回错误: %q", path)
			}
		}
	})
}

func TestDirAcceptEmptyDirectory(t *testing.T) {
	files, err := scan.Dir(t.TempDir())
	if err != nil || len(files) != 0 {
		t.Fatalf("合法空目录应成功返回空结果: files=%v err=%v", files, err)
	}
}

func TestDirKeepsRelativePathsAfterClean(t *testing.T) {
	directory := t.TempDir()
	if err := os.WriteFile(filepath.Join(directory, "chapter.md"), nil, 0600); err != nil {
		t.Fatal(err)
	}
	files, err := scan.Dir(directory + string(os.PathSeparator) + ".")
	if err != nil || len(files) != 1 || files[0] != "chapter.md" {
		t.Fatalf("路径规范化后仍应返回相对路径: files=%v err=%v", files, err)
	}
}

05

接入顺序与验收标准

  1. 更新 scan/scan.go，先拒绝空路径，再统一根路径表示。
  2. 更新 scan/walker.go，增加 fmt 导入，在根回调验证 d.IsDir()。
  3. 更新 main.go 的业务错误分支，使用 stderr 和退出码 1。
  4. 加入根路径回归测试，运行扫描测试与项目现有测试。
  5. 在自己的测试环境检查：无效根路径失败时，没有提交本次目录和文章增删，进程状态为非零。

P1 验收

非目录根路径必须返回错误，并在比较和落盘前停止；不能因为这次无效输入删除旧树后代。

P2 验收

初始化或同步失败都写入 stderr，返回退出码 1；同步成功继续输出报告，返回退出码 0。
